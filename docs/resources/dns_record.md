# netboxplugins_dns_record (Resource)

NetBox DNS record.

Plugin: `netbox-plugin-dns` (experimental). API: `/api/plugins/netbox-dns/records/`.

Only attributes set in the configuration are managed: an optional attribute left out takes the value NetBox holds and is never sent. To clear a value, set it explicitly (`""`, `[]`). For `custom_fields`, only the keys set in the configuration are managed.

## Example Usage

```terraform
resource "netboxplugins_dns_record" "www" {
  zone  = netboxplugins_dns_zone.example.id
  name  = "www"
  type  = "A"
  value = "192.0.2.10"
  ttl   = 300
}
```
