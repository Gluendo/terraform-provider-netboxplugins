# netboxplugins_dns_zone (Resource)

NetBox DNS zone.

Plugin: `netbox-plugin-dns` (experimental). API: `/api/plugins/netbox-dns/zones/`.

Only attributes set in the configuration are managed: an optional attribute left out takes the value NetBox holds and is never sent. To clear a value, set it explicitly (`""`, `[]`). For `custom_fields`, only the keys set in the configuration are managed.

## Example Usage

```terraform
data "netboxplugins_dns_view" "default" {
  filters = { name = "_default_" }
}

resource "netboxplugins_dns_nameserver" "ns1" {
  name = "ns1.example.com"
}

resource "netboxplugins_dns_zone" "example" {
  name        = "example.com"
  view        = data.netboxplugins_dns_view.default.id
  nameservers = [netboxplugins_dns_nameserver.ns1.id]
  soa_mname   = netboxplugins_dns_nameserver.ns1.id
  soa_rname   = "hostmaster.example.com"
  status      = "active"
  default_ttl = 3600
}
```
