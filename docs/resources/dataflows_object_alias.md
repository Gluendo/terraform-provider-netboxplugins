# netboxplugins_dataflows_object_alias (Resource)

NetBox Data Flows object alias.

Plugin: `netbox-data-flows` (experimental). API: `/api/plugins/data-flows/objectalias/`.

Only attributes set in the configuration are managed: an optional attribute left out takes the value NetBox holds and is never sent. To clear a value, set it explicitly (`""`, `[]`). For `custom_fields`, only the keys set in the configuration are managed.

## Example Usage

```terraform
resource "netbox_ip_address" "web" {
  ip_address = "192.0.2.10/24"
  status     = "active"
}

resource "netbox_prefix" "clients" {
  prefix = "198.51.100.0/24"
  status = "active"
}

resource "netboxplugins_dataflows_object_alias" "web" {
  name         = "web-servers"
  ip_addresses = [netbox_ip_address.web.id]
}

resource "netboxplugins_dataflows_object_alias" "clients" {
  name     = "clients"
  prefixes = [netbox_prefix.clients.id]
}
```
