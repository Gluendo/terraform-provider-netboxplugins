# netboxplugins_dataflows_flow (Resource)

NetBox Data Flows flow.

Plugin: `netbox-data-flows` (experimental). API: `/api/plugins/data-flows/dataflows/`.

Only attributes set in the configuration are managed: an optional attribute left out takes the value NetBox holds and is never sent. To clear a value, set it explicitly (`""`, `[]`). For `custom_fields`, only the keys set in the configuration are managed.

## Example Usage

```terraform
resource "netboxplugins_dataflows_flow" "https" {
  name              = "clients-to-web"
  sources           = [netboxplugins_dataflows_object_alias.clients.id]
  destinations      = [netboxplugins_dataflows_object_alias.web.id]
  protocol          = "tcp"
  destination_ports = [443]
  status            = "enabled"
}
```
