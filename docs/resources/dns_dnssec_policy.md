# netboxplugins_dns_dnssec_policy (Resource)

NetBox DNS dnssec policy.

Plugin: `netbox-plugin-dns` (experimental). API: `/api/plugins/netbox-dns/dnssecpolicies/`.

Only attributes set in the configuration are managed: an optional attribute left out takes the value NetBox holds and is never sent. To clear a value, set it explicitly (`""`, `[]`). For `custom_fields`, only the keys set in the configuration are managed.
