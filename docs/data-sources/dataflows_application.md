# netboxplugins_dataflows_application (Data Source)

Reads one NetBox Data Flows application.

Plugin: `netbox-data-flows` (experimental). API: `/api/plugins/data-flows/applications/`.

## Example Usage

```terraform
data "netboxplugins_dataflows_application" "by_id" {
  id = 42
}

data "netboxplugins_dataflows_application" "by_filter" {
  filters = { name = "example" }
}
```
