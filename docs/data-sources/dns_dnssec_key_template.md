# netboxplugins_dns_dnssec_key_template (Data Source)

Reads one NetBox DNS dnssec key template.

Plugin: `netbox-plugin-dns` (experimental). API: `/api/plugins/netbox-dns/dnsseckeytemplates/`.

## Example Usage

```terraform
data "netboxplugins_dns_dnssec_key_template" "by_id" {
  id = 42
}

data "netboxplugins_dns_dnssec_key_template" "by_filter" {
  filters = { name = "example" }
}
```
