# netboxplugins_dns_record_template (Data Source)

Reads one NetBox DNS record template.

Plugin: `netbox-plugin-dns` (experimental). API: `/api/plugins/netbox-dns/recordtemplates/`.

## Example Usage

```terraform
data "netboxplugins_dns_record_template" "by_id" {
  id = 42
}

data "netboxplugins_dns_record_template" "by_filter" {
  filters = { name = "example" }
}
```
