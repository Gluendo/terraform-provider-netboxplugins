# netboxplugins_dataflows_object_alias (Data Source)

Reads one NetBox Data Flows object alias.

Plugin: `netbox-data-flows` (experimental). API: `/api/plugins/data-flows/objectalias/`.

## Example Usage

```terraform
data "netboxplugins_dataflows_object_alias" "by_id" {
  id = 42
}

data "netboxplugins_dataflows_object_alias" "by_filter" {
  filters = { name = "example" }
}
```
