# netboxplugins_dns_zone_template (Data Source)

Reads one NetBox DNS zone template.

Plugin: `netbox-plugin-dns` (experimental). API: `/api/plugins/netbox-dns/zonetemplates/`.

## Example Usage

```terraform
data "netboxplugins_dns_zone_template" "by_id" {
  id = 42
}

data "netboxplugins_dns_zone_template" "by_filter" {
  filters = { name = "example" }
}
```
