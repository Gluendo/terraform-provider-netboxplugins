# netboxplugins_dns_dnssec_policy (Data Source)

Reads one NetBox DNS dnssec policy.

Plugin: `netbox-plugin-dns` (experimental). API: `/api/plugins/netbox-dns/dnssecpolicies/`.

## Example Usage

```terraform
data "netboxplugins_dns_dnssec_policy" "by_id" {
  id = 42
}

data "netboxplugins_dns_dnssec_policy" "by_filter" {
  filters = { name = "example" }
}
```
